# ShopEase - Full Stack E-Commerce App

A complete MERN stack e-commerce application with Razorpay payment integration, admin dashboard, and JWT authentication.

## ✨ Features

- JWT authentication with httpOnly cookies
- Product listing with filters and search
- Cart management with stock validation
- Coupon/discount system
- Razorpay payment integration with signature verification
- Order tracking and management
- Admin dashboard with revenue analytics
- Cloudinary image uploads
- Email notifications via Resend

## 🛠️ Tech Stack

**Frontend:** React 19, Vite, Tailwind CSS v4, Zustand, React Router  
**Backend:** Node.js, Express 5, MongoDB, Mongoose, JWT  
**Payments:** Razorpay  
**Storage:** Cloudinary  
**Email:** Resend
